# Shield-Insurance-Analysis-2026
Welcome to my Shield Insurance Analysis project. This repository features a comprehensive business intelligence solution designed to provide a holistic view of policy performance across Sales, Age Group, and City segments for AtliQ Shield Insurance. The project utilizes advanced Power BI-based dashboarding and data modeling to evaluate key metrics including Total Revenue, Total Customers, Growth Rate, and Policy Count to monitor progress, identify trends, and drive data-informed strategic decisions.

## Project Description

This repository contains a specialized insurance analytics suite that provides a holistic view of Shield Insurance's policy and customer performance. Built across three dashboard pages
- Overview, Sales Mode Analysis, and Age Group Analysis 
- It evaluates critical metrics including Total Revenue, Total Customers, daily Revenue & Customer Growth Rate, and Month-over-Month policy changes. 
- The dashboard segments the customer base by age group and city, and includes a Revenue/Customer trend toggle alongside filters for sales mode, age group, city, month, and policy ID to make the analysis more efficient.

## Folder Structure
- *Assets* - Icons, logos, and other visual assets used across the dashboard
- *Dax-Measures* - Documentation of the DAX measures and calculation logic powering the dashboard (Total_Revenue, Total_customers, Policy_Count, Age Group segmentation, etc.)
- *MockUp* - Early design mockups and layout iterations explored before finalizing the dashboard
- *Report* - The finished dashboard, exported in PDF format
- *Style-Guide* - Color palette, typography, and design system reference behind the navy & gold theme

## Key features
- *Revenue & Customer Growth Tracking*
- *Month-over-Month Policy Trend Monitoring*
- *Age Group & City-Wise Segmentation*
- *Revenue/Customer Trend Toggle*
- *Multi-Filter Analysis (Sales Mode, Age Group, City, Month, Policy ID)*

## Installation
To explore or modify this Power BI project:

1. *Download and Open Power BI Desktop*
   - This analysis can be done using any recent version of Power BI
2. *Explore Resources*
   - Open the Dax-Measures folder to review the logic behind key metrics like Total Revenue, Total Customers, and Age Group segmentation
3. *Explore the Report*
   - Navigate to the Report folder to view the finished dashboard in PDF format
